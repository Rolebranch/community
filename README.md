# Rolebranch community

The place to learn Rolebranch, ask how something works, ask for something new and tell us when
something breaks. **[Open the Discussions →](https://github.com/Rolebranch/community/discussions)**

| Category | Use it to | |
| --- | --- | --- |
| 📖 **Help guides** | Read step-by-step guides from the team, and comment with questions about them | [Browse](https://github.com/Rolebranch/community/discussions/categories/help-guides) |
| 🙋 **Q&A** | Ask how to do something. Mark the reply that solved it as the answer | [Ask](https://github.com/Rolebranch/community/discussions/new?category=q-a) |
| 💡 **Ideas** | Ask for a feature, a template, a connector or a Romy ability. Upvote the ones you want | [Suggest](https://github.com/Rolebranch/community/discussions/new?category=ideas) |
| 🐞 **Problems** | Report something that doesn't work as it should | [Report](https://github.com/Rolebranch/community/discussions/new?category=problems) |
| 📣 **Announcements** | Hear what's new and what's coming, from the team | [Read](https://github.com/Rolebranch/community/discussions/categories/announcements) |

Before you post, search: someone may have asked already. An upvote (👍 on the post) tells us more
than a "+1" comment.

## Keep your CV private here

Discussions are **public**, and anyone on the internet can read them. Please don't post:

- your CV or cover letter text, or screenshots that show your name, email, phone or address;
- anyone else's personal details, or an employer's internal information;
- coupon codes, sign-in links or anything from your account settings.

When we need something private to look into a problem (a file that won't import, a charge that
looks wrong), send it through [rolebranch.com/help/request](https://rolebranch.com/help/request) or
[contact@rolebranch.com](mailto:contact@rolebranch.com) and say which discussion it belongs to.

**Found a security issue?** Don't post it here. Follow
[rolebranch.com/security](https://rolebranch.com/security).

## Ground rules

Be kind and stay on topic. Posts in English are answered fastest, but write in Deutsch, Français,
Español, Italiano or Українська if that's easier: we'll answer in your language. We remove spam,
promotion and anything that shares someone's personal details.

This repository holds only the community: Rolebranch's source code is private.
